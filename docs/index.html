Claude Code

Keep working.
Claude keeps you posted.

While Claude Code works — in Terminal, VS Code or the Claude app — the island shows the project, the step it's on, the steps just done and the time so far. It tells you the moment Claude needs your input, and when it's done.

  • Sets itself up when Claude Code is installed. One switch to turn it off.
  • One island per session, up to four at once.
  • Never sees your prompts or files — only the step, like "Editing App.swift".

Light and private

Feels like part of macOS.
Because it plays by its rules.

0%CPU when idle
22 MBof memory at rest
0trackers or analytics in the app
NativeSwift, SwiftUI and AppKit
Sandboxed

Runs in the App Sandbox using only public APIs. Calendar, Reminders, Bluetooth and the camera are asked for only when you turn them on.

Event-driven

Lintel waits for macOS to report changes instead of polling; only the System Monitor, if you turn it on, takes a quick reading every few seconds. Animations run on Core Animation and stop when hidden or with Reduce Motion.

Signed updates

Updates install themselves, and each one is checked against a signing key before it's trusted.

Questions

Is Lintel free?

Yes. Download it, use it, and get every update.

My Mac doesn't have a notch. Does it work?

Yes. On Macs and displays without a notch, Lintel floats as a small pill at the top centre of the screen, with the same activities.

Why does macOS warn me the first time?

Apps from outside the App Store need Apple's notarization to open without a prompt. Lintel isn't notarized yet, so macOS asks you once. After you allow it, updates install without asking.

What does Lintel see of my data?

Only what a feature needs, and only after you turn it on. Calendar and Reminders stay on your Mac. Claude Code status sees the step Claude is on — never your prompts or file contents. The app has no analytics. This website counts visits and download clicks with GoatCounter, without cookies or anything that identifies you.

How do I connect Claude Code?

Nothing to do: if Claude Code is installed, Lintel connects when it starts and tells you once. New Claude Code sessions appear in the island. Turn it off in Settings › Activities › Claude Code.

How do I uninstall it?

If you use Claude Code, first turn off Claude Code in Lintel's Settings so it removes its hook. Then quit Lintel from the menu bar and move it to the Trash, or, if you installed it with Homebrew, run brew uninstall --cask lintel.
